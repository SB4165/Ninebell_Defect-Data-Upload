# 부적합 양식 변환기

그룹웨어 메신저로 받은 부적합 메시지를 붙여넣으면 업로드 양식(15개 항목)으로 바꿔줍니다.

## 파일 구성
| 파일 | 역할 |
|---|---|
| `index.html` | 화면 전체 (설정은 파일 안 `CONFIG` 부분) |
| `model.json` | 불량내용 → 대/중/소분류 추천 모델 (관리대장 2025~2026 학습) |
| `mock/` | 테스트용 예시 데이터 (`index.html?mock=1` 로 열면 사용) |
| `tools/train_model.py` | 추천 모델 재학습 스크립트 |

## 실시간으로 읽는 구글시트 (링크 공유 '보기'면 충분)
| 항목 | 위치 | 찾는 방법 |
|---|---|---|
| 대/중/소분류 드롭다운 | 참조(2026) AD~AF열, 6.1 수입/공정 분류표 | '대분류·중분류·소분류' 제목 줄 아래부터, 다음 구역 제목 전까지 (6.2 제조검수표는 제외) |
| 귀책 드롭다운 | 참조(2026) AD~AE열, 6.3 귀책 | '대분류·세부귀책' 제목 줄 아래 전부 |
| 장비타입 | 참조(2026) L열(발주명) / M열(TYPE) | 'PROJECT DESC (발주명)·TYPE' 제목 줄 아래 |
| 품명/품번 | 품명/품번 시트 C열 / D열 | 전체 (한 칸에 `A / B`처럼 여러 품번이 있으면 각각 검색) |
| 같은 문구 이력 | 수입공정 부적합 (2026) K~S열 | 제목 줄(귀책업체/대분류/…/불량내용)로 열 위치 확인 |

제목 글자로 표를 찾으므로 중간에 행을 넣거나 빼도 그대로 동작합니다. 빈 줄은 무시합니다.
열(AD/AE/AF, L/M, C/D) 자체를 옮길 때만 `index.html`의 `CONFIG`를 바꿔주세요.

## GitHub Pages 배포
1. GitHub에서 새 저장소 생성 (예: `nc-converter`, Public)
2. 이 폴더의 파일을 전부 업로드 (Add file → Upload files)
3. Settings → Pages → Branch: `main` / `(root)` → Save
4. 1~2분 뒤 `https://<계정명>.github.io/nc-converter/` 접속 → 팀에 공유
   (모바일은 홈 화면에 추가하면 앱처럼 사용 가능)

## 추천 모델 자동 재학습 (매주 월요일 03:00)
- `.github/workflows/retrain.yml`이 매주 구글시트를 내려받아 `tools/train_model.py`로 다시 학습하고 `model.json`을 교체합니다.
- 학습 데이터: 이름이 `수입공정 부적합 (연도)` 꼴인 시트 전부 (2025년 이후). 불량내용(S) → 대/중/소분류(L/M/N), 귀책업체(K) 함께 사용.
- 최근 60일 데이터로 먼저 검증하고, 1순위 정확도가 45% 미만이면 교체하지 않습니다 (시트 구조가 바뀌었을 때 안전장치).
- 결과는 `model_report.json`에 기록 (학습 건수, 최근 정확도).
- 바로 돌리기: Actions 탭 → "추천모델 주간 재학습" → Run workflow

## 연도가 바뀔 때 (2026 → 2027)
- 사이트: `참조(올해)` → 시트 고유번호(gid) → `참조(작년)` 순서로 찾고, 제목 줄을 확인한 뒤 사용합니다.
  시트 이름만 바꿔도, 새 연도 시트를 새로 만들어도 자동으로 따라갑니다. 관리대장·프로젝트 표는 올해+작년을 합쳐 씁니다.
- 재학습: 이름에 연도가 들어간 관리대장 시트를 모두 찾아 학습합니다.
- 제목 줄 글자(대분류/중분류/소분류, 대분류/세부귀책, PROJECT DESC (발주명)/TYPE, 불량내용 등)만 유지해 주세요.
